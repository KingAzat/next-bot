## 🤖 Présentation

**NEXBOT** est une landing page futuriste présentant un robot conceptuel doté d'une intelligence artificielle avancée. Ce projet met en valeur une architecture technique de pointe, des capteurs innovants, un processeur neuronal (NPU) et des capacités de perception spatiale exceptionnelles.

## ✨ Fonctionnalités

- **Visualisation 3D interactive** : Intégration d'un modèle 3D du robot via [Spline](https://spline.design/)
- **Design moderne** : Interface minimaliste avec effets de glassmorphism
- **Animations fluides** : Transitions élégantes et curseur personnalisé
- **Responsive** : Adapté à tous les écrans (mobile, tablette, desktop)
- **Performances optimisées** : Utilisation de Canvas API pour les éléments interactifs

## 🛠️ Technologies utilisées

- **HTML5** : Structure sémantique
- **CSS3** : Variables CSS, Flexbox, Grid, animations
- **JavaScript (Vanilla)** : Interactivité sans framework
- **Spline Viewer** : Rendu 3D temps réel
- **Google Fonts** : Typographies Inter & Space Mono

## 🎨 Personnalisation

Le projet utilise des variables CSS pour faciliter la personnalisation :

```css
:root {
  --bg: #e4e4e4;           /* Couleur de fond */
  --text: #111111;         /* Couleur du texte */
  --accent: #111111;       /* Couleur d'accentuation */
  --panel: rgba(255, 255, 255, 0.5);  /* Panneaux glassmorphism */
}
```

Modifiez ces valeurs dans le fichier HTML pour adapter le thème à vos besoins.
